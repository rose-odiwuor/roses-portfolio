# Rose Odiwuor – Portfolio

Static site (HTML + compiled Tailwind CSS). No build step needed on Vercel.

## Deploy
1. Push this folder to a GitHub repo.
2. vercel.com/new → Import the repo → Framework: **Other** → Deploy.

## Edit
- Content: `index.html`
- Contact email: change `roseodiwuor0@gmail.com` (search the file) and `data-to="..."` on the form.
- After changing classes/colours: `npm install` then `npm run build:css` (config: `tailwind.config.js`).
- Original Stitch export kept in `src/stitch-original.html` and `DESIGN.md`.

## Projects
Cards live in the `#projects` section of `index.html`. Banner images are in `assets/projects/` (replace with real screenshots any time, keep roughly 3:1).
